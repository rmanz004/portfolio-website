# Multimedia Portfolio Site

A free multimedia portfolio website hosted with GitHub Pages.

## Features

- Responsive design
- Audio player support
- YouTube embeds
- Smooth scrolling
- Fade animations
- Modern minimalist aesthetic

## Deployment

1. Create a GitHub repository
2. Upload all files
3. Go to:
   Settings → Pages
4. Under "Branch", select:
   main
5. Save

Your site will appear at:

https://yourusername.github.io/repository-name/
